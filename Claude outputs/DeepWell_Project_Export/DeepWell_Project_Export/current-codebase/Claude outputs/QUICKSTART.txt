  THE 8-STEP PIPELINE (Now Complete)
═══════════════════════════════════════════════════════════════════════════════

  1. Intake        → User uploads documents in batches
  2. Received      → Documents stored in Postgres
  3. Classified    → User assigns document type
  4. Extracted     → AI extracts fields
  5. Linked        → Documents linked to entities
  6. Verified      → User verifies correctness
  7. Answerable    → Data ready for queries
  8. Exported      → Warranty packets generated

  ✅ All steps persist to Postgres via usePostgresSync hook
