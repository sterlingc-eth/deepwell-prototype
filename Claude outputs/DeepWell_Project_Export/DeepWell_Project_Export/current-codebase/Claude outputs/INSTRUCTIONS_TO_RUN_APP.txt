    • Zustand (state management)

  Command:
    npm run dev

  Expected output:
    "Local: http://localhost:5173"

  ✅ DO NOT close this terminal window. Leave it running.

  WHAT IF SOMETHING GOES WRONG?
═════════════════════════════════════════════════════════════════════════════════

ISSUE: npm install fails
  FIX: Run "npm cache clean --force" then try again

ISSUE: Port 5173 is already in use
  FIX: Kill the process on that port or run "npm run dev -- --port 3000"

ISSUE: Still seeing the marketing landing page
  FIX: Verify you have index.html in the root directory
       Check browser console (F12) for errors

ISSUE: TypeScript errors
  FIX: These are normal during development. Browser will still load.
       Run "npm run typecheck" to see all errors at once
