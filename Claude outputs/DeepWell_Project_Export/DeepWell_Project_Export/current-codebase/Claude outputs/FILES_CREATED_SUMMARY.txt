═══════════════════════════════════════════════════════════════════════════════
  KEY DESIGN DECISIONS
═══════════════════════════════════════════════════════════════════════════════

1. VITE as build tool
   - Fast HMR (hot module replacement)
   - Native ES modules
   - Minimal config
   - Supports React out of the box

2. TypeScript for type safety
   - Full type coverage for domain model
   - Types defined in src/core/types.ts
   - Zustand for state management (typed)

3. Tailwind CSS for styling
   - Utility-first CSS framework
   - Configured with postcss
   - Global styles in src/index.css

4. Screen-based architecture
   - App.tsx routes between screens
   - useAppStore for navigation
   - Each screen is a self-contained component

5. Service abstraction layer
   - recordsStoreClient abstracts API calls
   - Makes Postgres sync transparent
   - Can be swapped for different backends

6. Hook-based sync
   - usePostgresSync runs on app startup
   - Watches graph state changes
   - Auto-syncs to Postgres via API
