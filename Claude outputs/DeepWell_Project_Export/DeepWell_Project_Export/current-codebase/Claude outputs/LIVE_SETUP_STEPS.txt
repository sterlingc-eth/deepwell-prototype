  STEP 1: CREATE DATABASE SCHEMA (One-time, 2 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://console.neon.tech (your Neon project)
2. Click "SQL Editor" on the left
3. Paste the entire content of init-schema.sql
4. Click "Execute"
5. Wait for success message

This creates:
  ✓ All 10 tables (documents, facets, extractions, entities, etc.)
  ✓ Row-Level Security policies (tenant isolation)
  ✓ Indexes for performance
  ✓ Default tenant

═══════════════════════════════════════════════════════════════════════════════
  STEP 2: UPDATE ENVIRONMENT VARIABLES (2 minutes)
═══════════════════════════════════════════════════════════════════════════════

In your local deepwell-prototype folder, edit .env.local:

CHANGE THIS LINE:
  CLERK_PUBLISHABLE_KEY=pk_test_...

TO THIS (add VITE_ prefix):
  VITE_CLERK_PUBLISHABLE_KEY=pk_test_...

Keep everything else the same.

═══════════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════════

Copy these files to your local repo:

  1. Replace src/App.tsx with the new App.tsx
  2. Replace src/main.tsx with the new main.tsx
  3. Create new file src/screens/LoginScreen.tsx (copy LoginScreen.tsx)

Then install Clerk package:

Vercel will automatically:
  ✓ Detect the push
  ✓ Install @clerk/clerk-react

  ✓ Deploy to deepwell-prototype.vercel.app

Wait 2-3 minutes, then refresh https://deepwell-prototype.vercel.app
