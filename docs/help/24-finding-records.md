Records opens on **Documents** the first time you use it, then remembers the last tab you used. Search, filters and views all live inside its tabs.

### Where are my documents and customers?
~ where are my documents, where are my customers, where are my records, records screen, records tab, where did my documents go, where do i see uploaded files, list of documents, find my files, browse documents, customers tab, documents tab, where did search go, search screen, old search
!covers:A-RECORDS-TABS
Open **Records**. The tabs are **Documents** (where a new user lands first), **Customers**, **Company Files** and **Grid**. Records reopens on the tab you used last. Your uploaded files are under **Documents**. The old separate Search screen is gone: use the search boxes in Customers and Documents, or press Ctrl+K (Cmd+K on a Mac).

### How do I search my documents?
~ search documents, search my documents, find a document, search by serial, search filename, search by address, search by technician, search by brand, search contents, find a work order, find an invoice, find a file, look for a document, document search, table or cards
!covers:A-SEARCH-DOCS
**Records → Documents**. The box reads "Search filename, customer, address, technician, brand, contents…". Results show as a table (Name, Type, Customer, Address, Date, Tech, Status, Amount) or as cards; click a row to preview it. To ask about what's inside, use the Ask screen instead.

### How do I filter documents by type, status or warranty?
~ filter documents, filters button, filter by type, filter by status, filter by technician, filter by customer, filter by date, filter by brand, only my uploads, my uploads, has money, open balance, expired warranty filter, needs review filter, missing info filter, clear all filters, service date range, documents from one technician, find all documents from one technician, documents by technician, find documents from a technician
!covers:A-FILTER-DOCS
In **Records → Documents** press **Filters**. You can filter by Type, Status (Verified, Needs review, Missing info), Warranty (Expired, Expiring 90 days, Active, No warranty on file), Customer, Site, Technician, Brand, Money (Has money, Open balance), My uploads, Service date range and Upload date range. Active filters show as chips; **Clear all** resets them.

### How do I sort or group documents?
~ sort documents, group documents, sort by newest, sort by customer, group by customer, group by month, group by site, group by type, table view, card view, internal documents, team only, audience customer internal, order documents, newest first
!covers:A-SORT-GROUP
In **Records → Documents**: **Sort** (Newest upload, Newest service date, Customer A–Z, Type, Amount), **Group** (No grouping, Customer, Type, Month, Site) and the table/card buttons. The **Audience** control switches between Customer, Internal and All; Internal documents are team-only and badged "Team only".

### How do I save a filtered view?
~ saved views, save a view, save current view, save my filters, saved filters, warranties expiring 90 days, this months invoices, needs review view, delete a saved view, share a view, bookmark a filter, remember my filters
!covers:A-VIEWS
In **Records → Documents** set your filters and press **Save current view**, name it and **Save**. Built-in views are **Needs review**, **Warranties expiring 90 days**, **This month's invoices** and **My uploads**. Delete one with the x. Views are saved in this browser only, but the URL holds the filters so you can share the link.

### How do I search or filter customers?
~ search customers, find a customer, customer search, filter customers, customers with expiring warranties, customers with alerts, customers by city, last activity, sort customers, customers with no equipment, find by phone, find by email, find by address, customer list, customers whose warranties are expiring, look at customers whose warranties are expiring, customers with warranties expiring
!covers:A-CUSTOMER-SEARCH
**Records → Customers**. Search "Search by name, address, phone, or email…". Filters: Alerts (Expiring soon, Expired, Needs attention, No alerts), Equipment (Has units, No units on file), City and Last activity (30, 90 or 365 days). Sort by Recent activity, Name A–Z, Address A–Z, Most documents, Most equipment or Alerts first. **Clear all** resets.

### How do I add a customer?
~ add a customer, new customer, create a customer, add customer manually, add a new customer, enter a customer, customer not in the list, customer isnt showing, where do customers come from, customers appear automatically, how do customers get added
!covers:A-CUSTOMER-NEW
In **Records → Customers** press **New customer** and fill in Name, Address, Phone and Email. You usually don't need to: customers appear automatically as documents are read and matched.

### What's on a customer's profile?
~ customer profile, open a customer, edit a customer, change customer phone, change customer address, edit customer name, customer notes, save notes, customer timeline, customer equipment, customer documents, assign a document to a customer, customer overview, call a customer, email a customer, open reminders, notes on a customer, put notes on a customer, where do i put notes, where do i put notes on a customer
!covers:A-CUSTOMER-PROFILE
Click a customer row. Click a value (Name, Address, Phone, Email) to edit and save it; Call and Email links sit beside them. Tiles show Documents, Equipment, Next warranty expiry and Open alerts, and tabs cover Documents, Equipment, Timeline, Graph and Notes (type, then **Save notes**). **Assign a document to this customer** links one from there.

### What is the Grid?
~ grid, records grid, spreadsheet view, spreadsheet of my units, table of units, columns picker, load more rows, load all rows, filter by model or serial, list all units, all my equipment, export grid, see all serial numbers, list of serial numbers, every unit in a spreadsheet, see every unit in a spreadsheet, all units in a spreadsheet, see every unit
!covers:A-GRID
**Records → Grid** is a spreadsheet of Documents or Units. Use "Filter by model or serial…", the **Columns** picker (remembered), **Load more rows** or **Load all (up to 5,000)**, and **Export CSV (N rows)** to download what you see.

### What is the Graph?
~ graph, knowledge graph, records graph, relationship map, see connections, how are things connected, graph view, graph tab, map of customers and equipment, connections between customers and units
!covers:A-GRAPH
The **Graph** toggle on a customer or record draws customers, properties, equipment and documents and how they connect. Click a node to open it. It's for exploring; for a specific answer use the Ask screen.

### Where is a unit's page?
~ unit page, equipment page, equipment record, open a unit, open a serial, unit details, unit history, service visits for a unit, documents for a unit, serial number page
!covers:A-EQUIPMENT-PAGE
Click any serial (in an answer, the Dashboard, a customer's Equipment tab or the Ctrl+K search) to open the unit page: its fields with their sources, related service visits and "Documents linked to this record". The page also has an **Install date** box (see the next answer).

### How do I add or change a unit's install date?
~ install date, add install date, edit install date, change install date, enter install date, set install date, type install date, install date on a unit, where do i edit install date, unit has no install date, no warranty on file needs install date, install date missing, fix install date, wrong install date, put in the install date, save install date, warranty from install date, installed date
!covers:A-INSTALL-DATE
Open the unit's page (click its serial, or press **Add install date** / **Change install date** in the Dashboard's warranty lists, which opens the page with the date box ready). In the **Install date** box press **Add install date** (or **Change install date**), pick the date and press **Save**. Anyone signed in to your company who can correct records can do this, members included. The date must be after 1950 and no more than about three months ahead. The page then shows "entered by" your name and the date it was typed; a date that came from a scanned document shows the document as its source. If DeepWell has a verified rule for that brand, the warranty is worked out from the new date right away; a printed expiry already on a document is kept, and a brand with no verified rule keeps the date but gets no computed expiry.
