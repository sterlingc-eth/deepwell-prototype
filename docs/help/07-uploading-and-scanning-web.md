Records go in through the Inbox in the web app, or through Scan in the phone app. Nothing has to be renamed or filed first.

### How do I upload documents?
~ upload, how do i upload, upload documents, upload files, add documents, add records, import records, drag and drop, drop files, get my files in, bulk upload, import documents, where do i upload, upload pdf, ingest, send files, upload work orders, upload my work orders, upload invoices, upload warranty cards, upload photos, upload my files
Open **Inbox** in the web app and drag files in, or choose files. You can drop a whole folder as a zip. DeepWell reads each file and files the facts. Most documents are searchable within minutes.

### What file types can I upload?
~ file types, file formats, supported formats, supported file types, pdf, jpg, png, tiff, csv, zip, word, excel, docx, xlsx, heic, what can i upload, allowed files, unsupported file, what image formats, image formats, what formats do you accept, formats accepted, what image formats do you accept, accepted formats, which formats, photo formats
PDF, JPG or JPEG, PNG, WEBP, TIFF, TXT, CSV and ZIP. Photos of paperwork and nameplates work. If you have Word or Excel files, save them as PDF first.

### Is there a file size limit?
~ file size, size limit, max size, maximum file size, too big, too large, file too large, upload limit, how big can a file be, megabytes, mb limit
Files are limited to 100 MB each. Very large scans may hit smaller processing limits. If an upload fails for size, split the PDF into smaller files or email support@deepwelltechnology.com.

### How long until an upload is searchable?
~ how long, how long does it take, processing time, how fast, searchable, ready to search, wait time, when will it be ready, turnaround, how quickly, upload speed, how soon
Usually within minutes. Each document moves through **received, read, mapped, linked and verified**. Large batches take longer. You can watch the status in Inbox.

### Can DeepWell read handwriting and bad scans?
~ handwriting, handwritten, bad scan, blurry, poor quality, low quality, carbon copy, faded, cursive, scanned copy, crooked, photo quality, can it read my writing, read handwriting on old carbon copies
Yes. DeepWell reads handwriting, carbon copies and low-quality scans. When a read is uncertain it flags the document for a quick human check instead of guessing.

### Can I forward emails or sync a folder?
~ email intake, forward email, forward emails, email to upload, folder sync, google drive sync, dropbox, sync folder, auto import, automatic import, shared drive, forward invoices, inbox forwarding
Email intake and folder sync are marked **coming soon** and are not available today, and I can't give a date. For now, upload files in Inbox or use the phone app to scan. For a big backlog, our team runs the first bulk ingest during setup.

### Can my whole backlog of paper be scanned for me?
~ backlog, lots of paper, thousands of pages, filing cabinet, banker boxes, scan everything, bulk ingest, large backlog, years of records, migrate my paper
Yes. White-glove setup includes a first bulk ingest, and Records Rescue can scan paper for you at ${{rescue.rate}} per page with a ${{rescue.min}} minimum. Start with a free sample box.
