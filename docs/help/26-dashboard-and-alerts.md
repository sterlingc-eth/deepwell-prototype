The **Dashboard** is where warranty expirations and data health live.

### What is on the Dashboard?
~ dashboard, what is on the dashboard, data health, dashboard sections, overview, equipment at risk, what do the tiles mean, dashboard tiles, collapse a section, dashboard explained, ai verified tile, needs linking tile, missing info tile, conflicts tile
!covers:A-DASH
Collapsible sections: **Data health** (Documents, AI verified, Needs linking, Missing info, Conflicts; duplicates are held out of every count), **Financials** (admin), **Alerts**, **Overview** (Documents, Units on record), **Warranty expiry · next to expire first**, **Equipment at risk** and **Customer outreach**. Data health tiles open the matching chip in Inbox → Needs you.

### What do the alert cards mean and what can I do with them?
~ alert cards, alerts, expired, this quarter, expiring in 30 days, expiring in 90 days, expiring in 12 months, registration closing, upsell candidates, dismiss an alert, undo dismiss, view customer, ask about this unit, no units expiring this quarter, warranty alerts on dashboard
!covers:A-DASH-ALERTS
Cards: **Expired**, **This quarter (30+90d)**, **Expiring in 30 days**, **Expiring in 90 days**, **Expiring in 12 months**, **Registration closing** and **Upsell candidates**. Open one to see its units; each has **View customer**, **Ask about this unit**, **Open in Outreach**, **Dismiss** (then **Undo**) and a checkbox to add it to a claim packet.

### How do I see which warranties are expiring?
~ which warranties are expiring, warranty table, warranty expiry, expiring warranties list, next to expire, covered units, no warranty on file, add install date, needs install date, copy link, ask next 12 months, all or this quarter, list of expiring units, units expiring soon, about to end, warranties about to end, which warranties are about to end, which warranties are ending, ending soon, units i need to add an install date to, which units need an install date
!covers:A-DASH-EXPIRY
On the **Dashboard**, the **Warranty expiry · next to expire first** table has **All** and **This quarter**, with Unit, Location, Expires and Status. Each row has **Copy link**, **Ask** and **Ask: next 12 months**. Below are "Covered" and "No warranty on file — needs install date" lists; **Add install date** opens the unit page, which has no date field, so upload the install paperwork.

### How do I prepare a warranty claim packet?
~ claim packet, warranty claim packet, prepare claim packet, warranty claim, make a claim, file a warranty claim, claim pdf, download pdf, packet preview, add a unit, select all units, why is download pdf greyed out, download pdf disabled, warranty expired cant download, no verified documents
!covers:A-CLAIM-PACKET
Tick units in the Dashboard alerts or table and press **Prepare claim packet (N)**. In **Warranty claim packet** you can add a unit, **Select all** or **Clear**, remove one with the x, check the **Packet preview** and press **Download PDF**. The PDF stays disabled until every unit has verified documents; the reason shows ("Warranty expired", "Missing …" or "No verified documents"). Check the documents in Inbox → Needs you first.

### What is the Financials card?
~ financials, financials card, dollar totals, revenue, money on dashboard, invoice totals, what did donovan count, money not counted, backfill, financial totals, why is my total low, invoices counted
!covers:A-FINANCIALS
Admins see **Financials** on the Dashboard: totals Donovan counted from your invoices, and a note of what it couldn't count. An admin can start the backfill there to pick up older invoices. Wrong figures are corrected on the invoice under "Money on this document".

### What is the Donovan button in the header?
~ donovan button, donovan admin, answer quality, misses, learning, scorecard, run scorecard, search by meaning, prepare older documents, questions donovan couldnt answer, replay a question, admin donovan panel, what is the donovan overlay
!covers:A-DONOVAN-ADMIN
Admins only. **Donovan** opens Answer quality: **misses** (questions Donovan couldn't answer, to replay or copy for review), **learning** (proposals you can keep as tests), the **scorecard** (**Run scorecard**) and **Search by meaning → Prepare older documents**. Members don't see it.
