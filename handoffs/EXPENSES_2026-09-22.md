# Owners-only expense tracker (2026-09-22)

DeepWell's own business expenses (software, AI/cloud spend, travel, ...) —
never a tenant's data, never visible to a customer. Gated end to end by
`isPlatformOperator` (`api/_lib/missDigest.js`): the founder tenant, or a
Clerk user id on `DEEPWELL_OPERATOR_USER_IDS`. A tenant's own admin, even a
founder-shop non-founder admin, gets 403 on every op.

## 1. Paste this migration

Run `M3-config/28-expenses.sql` against Neon (psql or the SQL editor), after
`26-donovan-learning.sql`. Idempotent — safe to re-run. Creates
`platform_expenses` (RLS enabled + FORCE, zero policies) and five
`SECURITY DEFINER` functions (`expenses_list/insert/update/delete/totals`) —
the only door in, same shape as the Donovan-learning tables. Until it's
pasted, every op answers a clean 503 ("needs a database update") instead of
a raw 500 — code already tolerates it missing.

## 2. How to use it

Sign in as the founder tenant (or an allowlisted operator user id) and an
**Expenses** item appears in the top nav (`Receipt` icon) — nowhere else,
and never for a regular shop. The screen has:

- **Range toggle**: This month / This year / YTD / Custom.
- **Totals**: grand total plus a bar per category for the selected range.
- **Add expense**: manual form, or **upload a receipt** (PDF/photo) —
  one Haiku call reads vendor, date, total, and guesses the category, then
  prefills the form for you to confirm before it saves anything.
- **Table**: inline edit/delete per row, receipt filename shown when one's
  attached.
- **Export CSV** for the selected range.
- **Seed starter entries** button — shows only while the table is empty;
  inserts the three known September Anthropic/Claude Max charges.

Deep link: `/app?screen=expenses`, or the redirect page at
`/expense-tracker.html`.

### Update (2026-09-23)

- **Monthly log** (default view): year total, each month newest first with total, count, top categories; expand for rows. Year picker for prior years. Export a month or the year (CSV has `Receipt Filename` + `receipt_on_file` yes/no). `monthly {year}` op aggregates in JS from `expenses_list`; no new DDL.
- **View / attach receipts**: `receiptViewUrl {id}` returns a 5-minute presigned GET (key read from the DB row, must be under `platform/expenses/`). Any row can Attach/Replace a receipt.
- **Fast capture**: "Take photo" (`capture=environment`) or "Upload receipts" (multiple). Files upload + extract one at a time into a review queue; Save/Skip each, nothing saves unconfirmed. HEIC is rejected with a "use JPG/PDF" message.
- Categories unchanged: 28's CHECK constraint fixes the list (adding one needs DDL).

## 3. Cost

Receipt extraction is one Haiku (`claude-haiku-4-5`) call per receipt: a
single small image plus a short tool schema, ~300 output tokens. Measured
against Haiku's per-token pricing this comes out to roughly **$0.002 per
receipt** — DeepWell's own operating cost, not billed to any tenant (no
`recordModelCall`/usage-row write; see the log line in
`api/_lib/routes/expenses.js`'s `handleReceiptExtract`).

  dispatched by `op`; operator-gated before any DB/rate-limit work.
- `src/services/expensesClient.ts`, `src/screens/ExpensesScreen.tsx`.
- `src/components/AppShell.tsx` — nav item gated on `isPlatformOperator`
  (fetched once in `App.tsx` via the new `operatorStatus` op).

- `public/expense-tracker.html` — redirects to `/app?screen=expenses`.

No new top-level `api/` file (still 12; `ls api` = 13 counting `_lib/`), no
new dependency.
